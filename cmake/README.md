# Phase 2 native adapter build inputs

CommonLibSSE-NG 7.2.0 is now used for the verified native Camera/Scaleform interfaces, as conditionally selected in ADR-001. Source is fetched at `7a60f4de794095d7b0f8928d1b930a52e9a7da83`; no provider/runtime version changes. Its vcpkg baseline `ee12231b20c95013c6638d845d04c91559a1d1ff` also pins the tool checkout and transitive dependency resolution. The manifest requests only spdlog, DirectXTK and rapidcsv needed by the selected CommonLib build. Build uses MSVC x64, C++23 as required by CommonLib, static CRT and static vcpkg triplet, AE only, without upstream test suite, IPO or trampoline decoder. No prebuilt CommonLib binary is substituted.

Configure from a VS2022 x64 environment with the pinned vcpkg toolchain and `-DVCPKG_TARGET_TRIPLET=x64-windows-static`. Select `-DSKYCRPG_BUILD_CAMERA=ON -DSKYCRPG_BUILD_UI=OFF` (reverse for UI). Build `SkyCRPG_Camera` or `SkyCRPG_UI` with `--parallel 2`. Package using `python tools/package.py --module camera|ui --build-dir <build> --commit <exact SHA>`.

CI records the branch head, builds only changed module targets, and stores archives/manifests and diagnostic files. Shared-header-only or unclassified changes select both targets in independent jobs. First source dependency build budget is 30 minutes. Local warm builds remain bounded to 15 minutes. A successful build is not gameplay acceptance. The previous automatic second full clean build is no longer run per leaf change; binary cross-directory reproducibility remains unverified for the new adapters and must be checked at the packaging gate.

CommonLib remains a build-time source dependency statically linked independently into each module; no shared runtime service or module-to-module import. Original code retains MIT; CommonLib COPYING and EXCEPTIONS are retained separately under LICENSES. The exact external source URL and build pins must accompany any candidate containing it. Final linked-distribution rights/corresponding-source packaging remains DYL-171/174; these internal candidates are not a public release.
