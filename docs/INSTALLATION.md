# Installing internal candidates

These instructions describe the assembled internal candidates, not a public release. Fresh installation, update, disable and removal on the final archives are **NOT_RUN**; game builds are not claimed tested without evidence. Use an isolated mod-manager profile and a copied save. See [limitations](RELEASE_NOTES.md), [controls](CONTROLS.md), [packaging evidence](evidence/p4/packaging.md), and the [runtime matrix](compatibility/runtime-matrix.md).

## Requirements

Install externally: Steam Skyrim SE 1.7.104.0, SKSE64 2.3.1, Address Library 13, and SkyUI Community 6.11 for either module. Camera also requires SmoothCam 1.8.1, True Directional Movement (TDM) 2.3.1 and MCM Helper 1.6.3. UI's minimap is optional: install Infinity UI NG 2.1.3, Local Map Upgrade settings fork 1.3.4 and Dragon's Eye Minimap settings fork 1.7.5, each with Common + Line-17, as a complete stack. Without it the native compass remains. See the [dependency lock](compatibility/dependency-lock.md) for sources, hashes and configuration. Other builds and stacks are untested. The only host with gameplay evidence is the recorded Steam/Proton host; the final candidate is not yet game-tested.

Use `SkyCRPG_Camera-0.1.0-rc.1-<sha7>.zip` and/or `SkyCRPG_UI-0.1.0-rc.1-<sha7>.zip`, with the matching manifests and SHA256SUMS. Verify hashes and source commit before installing; final hashes are `<candidate archive hashes>` and source `<candidate SHA>`. ZIP paths are relative to Data. Each module is independent; neither requires the other.

## Fresh profiles: MO2 and Vortex

1. Close the game. Create a separate profile and copy the save; install SKSE and the external requirements for the chosen module as directed by their providers. Keep each provider in its own manager layer.
2. In MO2 use **Install a new mod from an archive**, select the Camera archive for camera-only, the UI archive for UI-only, or install both as separate mods for combined. Enable the selected layers and place each after its providers in the left-pane priority order so its files win. In Vortex install each archive via **Install From File**, enable it, resolve each listed file conflict with a rule to load the SkyCRPG layer after its provider, then deploy. Follow each manager's provider plugin ordering and SKSE launch setup.
3. Check the winners below before launching with SKSE. Leave other provider files and unrelated user settings intact. UI-only does not need Camera, SmoothCam or TDM; Camera-only does not need the UI archive or minimap stack. Test ordinary camera/UI, controls and navigation as appropriate. These fresh-profile manager routes are **NOT_RUN** for final candidates.

## Files and overrides

Each archive contains `SKSE/Plugins/SkyCRPG_Camera.dll` and `SkyCRPG_Camera.ini`, or `SKSE/Plugins/SkyCRPG_UI.dll` and `SkyCRPG_UI.ini`, respectively. Each has `Docs/<module>/` containing `CommonLibSSE-NG-COPYING`, `CommonLibSSE-NG-EXCEPTIONS.md`, `CommonLibSSE-legacy-MIT`, `build-inputs.md`, `LICENSE`, `LICENSING.md`, and `THIRD_PARTY.md`.

UI's `Interface/inventorymenu.swf`, `Interface/skyui/inventorylists.swf`, and `Interface/hudmenu.swf` are patched SkyUI 6.11 movies and must win over the SkyUI BSA. Camera's `SKSE/Plugins/SmoothCam.json` replaces SmoothCam's active config and `SKSE/Plugins/SmoothCamPreset0.json` replaces preset slot 0. Back up and reconcile any existing active settings and occupied preset with the game closed; the archive does not automatically merge an existing active config. Camera's `MCM/Config/TrueDirectionalMovement/settings.ini` replaces the TDM MCM settings file with a copy assembled from the pinned provider and Camera fragment; unrelated keys in that base are retained, but later user edits must be reconciled. Keep backups before installation and record the winner. Disabling the SkyCRPG layer restores the underlying provider files in the manager; preserve user edits made in the winning layer first. Do not delete provider files.

## Update, disable and removal

Close Skyrim completely before changing layers or INIs. Back up both module INIs and any edited winning SmoothCam/TDM settings, compare with the new candidate, install it as a new layer, reconcile edits and check conflict winners. Retain the old layer for rollback. Restart and verify the chosen profile; update and rollback are **NOT_RUN**. Do not assume safe mid-save uninstallation.

For Camera policy alone, set `[Camera] bEnabled=0` in `SKSE/Plugins/SkyCRPG_Camera.ini` and restart. Provider overrides remain; on disabled startup Camera does not request TDM's target-lock-disable lease. Enabling policy requests it again; F6 precision retains it. For UI, set `[HUD] bEnabled=0` in `SKSE/Plugins/SkyCRPG_UI.ini` and restart: the intended fallback is native HUD, inventory presentation, hotkeys and compass while movies remain installed. Both restart paths are **NOT_RUN**. To fully remove either module, quit, disable its complete manager layer, restore/reconcile underlying provider files, deploy if necessary, and restart the copied save. Keep the other module and shared prerequisites. Check movement, camera, inventory, menus and compass. Removal/restart remains **NOT_RUN**.

For emergency camera recovery F8 toggles SmoothCam; native Toggle POV returns to native view. If an interrupted F6 session cannot return, use native Toggle POV to reach third person, then F6 to enable the policy. F7 recenters; it is not a reset. Back up and replace the module INI with the shipped default while closed to reset settings. UI `[HUD] bResetLayout=1` selects default scale and offsets at restart without rewriting the file; set it back to 0 to use saved values. `[Inventory] bManageItemPreview=0` disables the in-memory preview adjustment after restart. UI malformed values use defaults or bounds; missing/invalid `[Minimap] bReplaceCompass` falls back off, although the shipped default is on. Malformed-file recovery passed on `p3-ini-167`; runtime schema mismatch and layout reset remain **NOT_RUN**.

## Troubleshooting

Check SKSE and module logs. Exact Camera messages include `Invalid Camera INI values: defaults or safe bounds applied; unsupported schema disables policy.`, `Camera disabled in INI; native camera controls remain available.`, and `Exact executable/provider prerequisite hash mismatch; controller disabled.` Restore the pinned prerequisites and valid settings. A loader rejection before DLL entry cannot produce a Camera log or notice; inspect SKSE's log and restore provider layers. Camera notice and failure routes are **NOT_RUN**.

UI logs `UI disabled by configuration; native UI and compass retained` when disabled, `Hotbar input event source unavailable; dispatch disabled` when its input source is missing, and `HUD resource snapshot: first unavailable/invalid sample; native fallback retained` for unavailable resources. If movies are missing or stock, use package/profile preflight; the DLL does not detect loaded SWF hashes. If the patched movies fail, disable the UI layer to restore stock SkyUI movies. If the optional minimap stack is absent or disabled, restore native compass; provider absence has bounded prior [evidence](evidence/p3/minimap.md), but final-candidate paths are **NOT_RUN**. The UI DLL cannot log if absent or rejected. On the recorded Proton host dialogue voices are silent even in a no-mod baseline; workarounds are unverified.
