## Scope and exclusions

These grants cover only original material and rights controlled by the rights holder. An existing file-specific third-party notice takes precedence for that material. Skyrim binaries/assets, third-party mod code, base SkyUI SWFs, embedded icons/fonts, provider artwork, downloaded saves and game screenshots containing external assets are **not relicensed** by these grants. Original patch snippets are MIT; a generated derivative SWF still contains separately governed material. Source visibility does not supply missing redistribution permission.

Provider archives remain external. TDM/CommonLib exceptions, GPL/corresponding-source obligations, SkyUI patch permissions and art/font rights must still be assessed for each shipped derivative under [THIRD_PARTY](THIRD_PARTY.md) and [dependency-lock](compatibility/dependency-lock.md#permissiondistribution-lock). DYL-171/174 own release packaging and notices. Resolving D015 does not authorize redistributing third-party packages or publishing a public release.
