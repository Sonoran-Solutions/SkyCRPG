[Architecture](../ARCHITECTURE.md) defines implementation contracts. Full-criterion status is conservative: **PASS** means all of the stated scoped check is evidenced; **FAIL** means a known unmet behavior; **NOT_RUN** means the full criterion lacks verification; **BLOCKED** means a named prerequisite prevents the selected route. A partial PASS in the evidence column never promotes a whole MVP criterion. A known failure can be accepted follow-up work without becoming a passing test.
