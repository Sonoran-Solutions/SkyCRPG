# Runtime and host matrix

No SkyCRPG runtime has been tested. Phase 1 selects one primary executable/storefront and host, then records versions and evidence here.

| Stack | Camera only | UI only | Combined | Disposition |
| --- | --- | --- | --- | --- |
| Primary runtime/host: pending P1 selection | NOT_RUN | NOT_RUN | NOT_RUN | Required MVP support baseline. |
| Other Steam executable versions | NOT_RUN | NOT_RUN | NOT_RUN | No support claim. |
| GOG variant | NOT_RUN | NOT_RUN | NOT_RUN | Deferred unless chosen as primary. |
| Additional Windows/Proton host beyond primary | NOT_RUN | NOT_RUN | NOT_RUN | Requires explicit validation. |
| VR, consoles, Legendary Edition | Out of scope | Out of scope | Out of scope | Separate product/porting work. |

Each tested row must include executable version, storefront, SKSE, Address Library, every selected provider version, build source commit, package hashes, host/Proton, graphics configuration, controller and links to evidence.

Native camera or UI fallbacks for difficult/special states are expected behavior. Unsupported states must not be labeled fully supported solely because the game did not crash.
