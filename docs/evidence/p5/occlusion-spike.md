### Recast progress, enclosure safety and bounds

**Source: current original spike code over `3293377`; portable policy PASS, native runtime NOT_RUN.** Each continuation advances along the ray from `max(start, projected contact)` by **max(30, 2 × hull)** world units: 30 for the observed 15-unit hull, 60 for SmoothCam's 30-unit lateral hull. A small negative penetration projection no longer prevents progress. At most eight continuations; invalid/non-finite inputs, a step reaching/passing the goal, interrupted authorization, caps or incomplete journals retain the original native result. A completed continuation miss explicitly returns the original goal and a null character; a non-allowlisted suffix contact returns its native end/contact/character unchanged.

A forward jump alone could skip a wall thinner than 30 units or start inside enclosure and receive a misleading miss. Before every jump, an **all-contact hull sweep** covers the entire current start→proposed start prefix using the engine's existing phantom, hull and filter, with the same collector for cast contacts and start overlaps. It must rediscover the original collidable. It checks every reported root, not just the first allowlisted beam. Unknown/non-allowlisted contacts, missing original contact, malformed parent chains or overflow roll back and disarm; an enclosure in the skipped interval therefore retains the original beam hit conservatively instead of manufacturing a clear result. This deliberately refuses closely overlapping beam/wall fixtures; it does not claim to reconstruct a new native wall hit from a partial query. Confirmed native exclusions (culled objects except layer 17, player on the caster's actor-layer branches) are honored; other ambiguity fails closed.

Bounds per outer caster call: **≤10 gateway invocations/hull writes** (first + eight continuations + one original-input reset), **≤8 guard sweeps**, **256 contacts/sweep**, **32 parent links/contact**, no collector heap growth. A cap stops accepting contacts and refuses the chain. Only the gateway positions/writes the native phantom; the guard is a query. One original-input gateway call restores its start after any continuation, including rollback. Hook-inclusive timing measures the full chain; original-inclusive includes the native sweeps, while guard resolution/journaling stays in adapter-exclusive time. Counts appear in `filter_complete`; `recast_gap` records caps, safety and original-contact rediscovery. A fixed invocation bound is not a millisecond budget PASS: actual ≤10% p95 remains **NOT_RUN**.

Portable fixtures exercise a beam then clear goal, beam then first of two walls, multiple allowed beams then wall, sub-diameter gap, touching/overlapping enclosure, an adversarial caster that misses from inside enclosure, an eight-step thick obstacle, near-goal refusal, empty ray, 15/30-unit hulls, finite values and contact caps. All four blocking findings were confirmed in the second-pass source and corrected. **PASS here means source/offline/portable verification only; all associated game rows remain NOT_RUN.**
